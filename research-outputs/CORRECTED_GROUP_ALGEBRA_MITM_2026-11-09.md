# 修正版群代数的精确 MITM 系数提取：t=7 与 t=69

**日期：** 2026-11-09  
**性质：** 对修正后的群代数目标系数进行精确 meet-in-the-middle 计算，并与独立整数表示枚举比较。

## 1. 修正后的局部因子

对 (D=\prod_i\ell_i^{a_i})，局部选择为：
- 每个 (0\le e<a_i)：两种方向，贡献模 M 指数 (e) 或 (2a_i-e)；
- (e=a_i)：剩余素数幂为1，只计一次，贡献指数 (a_i)。

因此第 i 个局部因子有恰好 (2a_i+1) 项。总配置数为
[
\prod_i(2a_i+1).
]

## 2. MITM 系数提取

每个局部选择贡献二元状态：
[
(\sigma_i,g_i)\in\mathbb F_2^m\times(\mathbb Z/M\mathbb Z)^\times.
]
将素数因子分成两半，分别建立稀疏状态表，键为 syndrome 与模 M 余数，值为产生该状态的局部配置数。

若左半状态为 ((s,x))，要使总状态成为 ((0,-D))，右半必须为
[
(s, -D\,x^{-1}\bmod M).
]
因此只需哈希查找互补状态，即可精确得到修正群代数系数 ([0,-D]P)。

## 3. 独立正确性核验

程序同时运行独立的 gcd 参数化枚举：逐个枚举 q，通过 Jacobi 条件后枚举 R=D/q 的互素因子分配，并直接检验 (M\mid r+s)。最终比较
[
[0,-D]P=2N(t).
]
该比较不是用同一个群代数程序自证，而是由不同的整数参数化枚举路径完成。

## 4. 运行规模与结果

运行脚本：
```bash
python research-outputs/corrected_group_algebra_mitm.py
```

程序将输出：
- 每个局部因子的 (2a_i+1) 个选择数；
- 两半原始组合数和合并后的稀疏状态数；
- 全部局部配置数；
- Jacobi 通过的 q 数；
- 修正群代数目标系数；
- 独立枚举得到的表示数及 ((q,r,s))。

必须满足：
[
[0,-D]P=2N(t).
]
已知回归条件为 t=7、69 均有 N=2，目标系数必须为4，且必须保留两种已知表示。

## 5. 边界

此程序验证的是有限参数上的精确系数恒等式，不给出一般参数的特征和估计、渐近上界或多项式时间算法。
