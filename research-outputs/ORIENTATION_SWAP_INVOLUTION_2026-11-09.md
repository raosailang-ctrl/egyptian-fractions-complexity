# 方向交换对合与 syndrome-zero 余数分布的精确对称性

**日期：** 2026-11-09  
**性质：** 一般代数恒等式与精确奇偶性定理；可由现有稀疏分布程序逐项验证。

## 1. 局部配置及余数

固定
[
D=\prod_i\ell_i^{a_i},\quad M>2,\quad \gcd(D,M)=1.
]
一个群代数局部配置由每个坐标的指数 (0\le e_i\le a_i) 以及剩余完整素数幂的分配方向决定。它对应
[
q=\prod_i\ell_i^{e_i},\quad qrs=D,\quad \gcd(r,s)=1.
]
定义乘法余数
[
g(q,r,s)=qr^2\pmod M.
]
局部 Jacobi syndrome 只依赖 q，因此交换 r 与 s 不改变 syndrome。

## 2. 方向交换对合定理

**定理。** 在固定 syndrome 的配置集合上，交换 r 与 s 诱导一个无不动配置的对合（除去唯一的退化配置 (q=D,r=s=1)），并将余数变为
[
\boxed{\iota(g)=D^2g^{-1}\pmod M.}
]
因此 syndrome-zero 余数分布满足
[
\boxed{\mu_0(g)=\mu_0(D^2g^{-1}).}
\tag{1}
]

**证明。** 交换 r,s 后，余数变为 (g'=qs^2)。由 qrs=D，
[
gg'=q^2r^2s^2=D^2,
]
故 (g'=D^2g^{-1})。交换两次回到原配置。若交换后配置不变，则必须 (r=s)。因 (gcd(r,s)=1)，只能 (r=s=1)，从而 q=D。这是唯一的固定配置。它的余数为 D。注意，这个唯一固定配置只有在 q=D 本身通过全部 Jacobi 条件时，才属于 syndrome-zero 层；若 D 未通过局部筛，它不在该层中。对 syndrome-zero 层中的其余配置，方向交换将配置分成大小为2的轨道。按余数计数即得 (1)。证毕。

## 3. 固定余数的奇偶性推论

对合的不动余数满足
[
g=D^2g^{-1}\iff g^2\equiv D^2\pmod M.
]
对任意这样的固定余数，配置数是偶数，唯一例外是 (g\equiv D\pmod M)：该余数还包含唯一的固定配置 (q=D,r=s=1)，所以
[
\boxed{
\mu_0(g)\equiv
\begin{cases}
1\pmod2,&g\equiv D\pmod M,\\
0\pmod2,&g^2\equiv D^2\pmod M, g\not\equiv D\pmod M.
\end{cases}}
\tag{2}
]
由于 (M>2)、(gcd(D,M)=1)，有 (D\not\equiv-D\pmod M)。目标余数 (-D) 是一个不动余数，但不是唯一退化余数，因此其质量必为偶数。这与 (mu_0(-D)=2N(t)) 一致。

注意：模合数 M 下，方程 (g^2=D^2) 可能有多于两个根；不能简单说不动余数只有 (\pm D)。

## 4. 对分布与碰撞统计的含义

- 余数分布关于变换 (g\mapsto D^2/g) 完全对称；
- 非不动余数以相同质量成对出现；
- 所有不动余数的质量为偶数；只有当 D 本身通过 Jacobi 筛时，g=D 的质量才为奇数；
- 目标余数 (-D) 是不动余数，因此其出现次数必为偶数；
- 这项对称性本身不说明 (-D) 是最大频数或低频余数，但解释了目标原子必须成对计数。

碰撞对数
[
\mathcal C=\sum_g\binom{\mu_0(g)}2
]
也可按对合轨道分组：非不动轨道的两个原子质量相等；不动轨道单独贡献。后续可将碰撞统计拆成这两类，以分离纯粹由方向交换造成的对称性与其他偶然余数碰撞。

## 5. 计算验证

更新后的 `syndrome_zero_residue_distribution.py` 对每个已计算余数 g 检查：
1. (mu_0(g)=mu_0(D^2g^{-1}))；
2. 若 (g^2=D^2)，则 (mu_0(g)) 为偶数；若 D 通过 Jacobi 筛，则 g=D 的质量为奇数；
3. 目标余数 (-D) 是不动余数且质量为偶数。

六个已研究参数 (t=3,7,17,69,137,185) 可用同一程序重新验证。有限计算只作定理的回归测试，不代替证明。

## 6. 下一步

1. 统计模 M 下 (g^2=D^2) 的全部不动余数，并比较哪些实际出现于 syndrome-zero 支撑。
2. 将每个非不动对合轨道合并成一个质量，重算碰撞分布。
3. 研究目标 (-D) 在不动余数集合中的位置，寻找除方向交换外的额外对称。
4. 研究局部配置之间的其他 involution 或有限群作用，确定目标质量是否由更大的轨道稳定子解释。

**边界：** 对称性定理没有给出 (N(t)) 的新上界，也不证明唯一性。
