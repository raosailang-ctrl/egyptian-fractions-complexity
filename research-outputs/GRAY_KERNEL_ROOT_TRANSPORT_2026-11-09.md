# Gray-code 核空间遍历与平方根传输：中心 K3 埃及分数族

**日期：** 2026-11-09  
**性质：** 线性代数参数化、模平方根传输公式与13个参数的精确有限验证；不是多项式时间算法，也不证明唯一性。

## 1. Jacobi 条件的完整二进制线性系统

令 (D=\prod_{i=1}^n \ell_i^{a_i})，其中 (ell_i) 是 D 的互异素因子。对 (h) 的互异素因子 (p_1,\ldots,p_m)，定义矩阵
[
A_{ji}=\begin{cases}
1,&(\ell_i/p_j)=-1,\\
0,&(\ell_i/p_j)=1.
\end{cases}
]
因为 (gcd(D,h)=1)，不会出现零 Legendre 符号。

写 (q=\prod_i\ell_i^{e_i}\mid D)。局部条件 ((q/p_j)=1) 对所有 j 成立，当且仅当
[
A v=0\quad\text{in }\mathbb F_2^m,
\qquad v_i=e_i\bmod2.
]
因此，所有通过筛选的 q 的奇偶指数向量，恰好是矩阵 A 的核空间。若 A 的秩为 r，则核空间维数为 d=n-r，共有 (2^d) 个可能的奇偶指数向量。每一个核向量都确实对应一个 D 的约数：取各指数 (e_i=v_i\in\{0,1\}) 即可。

## 2. 平方根传输与偶指数部分

记 (q_v=\prod_i\ell_i^{v_i})。对任意 q，其指数可唯一写为
[
e_i=2f_i+v_i,\qquad
S_q=\prod_i\ell_i^{f_i},
]
故
[
q=q_v S_q^2.
]

取共同基准根集
[
\mathcal Z_0=\{z\pmod M:z^2\equiv-D\pmod M\}.
]
因为 (v\in\ker A)，(q_v) 是模 M 的平方。存在 (w_v) 满足
[
w_v^2\equiv q_v^{-1}\pmod M.
]
于是
[
\boxed{\mathcal Z_q=S_q^{-1}w_v\mathcal Z_0.}
]
这把每个 q 的完整根集合，拆成三个部分：一次计算的基准根集、只依赖奇偶指数向量的核空间乘子，以及可直接求逆的偶指数平方部分。

## 3. Gray-code 核空间乘子的校正公式

取核空间的一组基 (b_1,\ldots,b_d\in\mathbb F_2^n)。对每个基向量定义
[
B_j=\prod_{i:b_{j,i}=1}\ell_i,
\qquad
u_j^2\equiv B_j^{-1}\pmod M.
]
若核向量写成 (v=\bigoplus_{j:c_j=1}b_j)，其中 (c_j\in\{0,1\})，令
[
n_i=\sum_{j=1}^d c_jb_{j,i},\qquad
C(v)=\prod_i\ell_i^{\lfloor n_i/2\rfloor}.
]
注意 (n_i) 是普通整数计数，而 (v_i=n_i\bmod2)。于是
[
\prod_{j:c_j=1}B_j=q_v C(v)^2.
]
因此
[
\left(C(v)\prod_{j:c_j=1}u_j\right)^2
\equiv q_v^{-1}\pmod M.
]
得到显式公式
[
\boxed{w_v=C(v)\prod_{j:c_j=1}u_j\pmod M.}
]

**为什么需要校正项？** 若两个核基向量都含有同一个素数 (ell_i)，直接相乘它们的平方根乘子会把 (ell_i^{-2}) 留在结果中；但在 F₂ 核向量相加时，这两个出现应当抵消。(C(v)) 正是把所有偶数重叠次数校正回去的因子。忽略该项会产生错误的平方根传输；程序中的回归测试确实捕捉到了这一错误。

现在按二进制反射 Gray code 遍历系数向量 (c)。相邻状态只切换一个基向量 (b_j)，所以乘积 (U=\prod u_j^{c_j}) 只需乘上 (u_j) 或 (u_j^{-1})。同时更新每个 (n_i)，即可得到新的 (C(v))。这样每个核向量不再需要重新执行局部平方根提取和 CRT；只需 d 次基向量根计算，再进行 Gray 遍历中的乘法更新。

## 4. 对每个 q 的根集

对具体约数 q，先取其奇偶向量 v，查得 (w_v)，再计算
[
S_q=\prod_i\ell_i^{\lfloor e_i/2\rfloor}.
]
于是根集直接由
[
\mathcal Z_q=S_q^{-1}w_v\mathcal Z_0
]
得到。这里的 (S_q^{-1}) 只是模 M 的乘法逆元，不需要再开平方根。

## 6. 这项结果的意义与边界

本轮得到一个明确的结构分解：平方根传输的昂贵部分只依赖于 Jacobi 矩阵核空间中的奇偶指数向量；同一奇偶类中不同 q 的差异只来自一个显式偶指数平方部分。

对 t=69，21,504 个通过筛选的 q 只对应 1,024 个奇偶类。因而完整根集合的传输乘子可由 10 个核基向量乘子生成，而不是为每个 q 重新进行局部平方根计算。这里的 1,024 个核类仍通过 Gray code 逐个遍历，并非免费；但根提取与 CRT 的次数从逐 q 计算变为逐核基向量计算。

这不是多项式时间算法。核维数 d 可能随参数增长，(2^d) 仍可能很大；每个 q 的互素因子分配与 MITM 也仍然具有指数规模。有限实验没有证明一般唯一性或 P/NP 结论。
