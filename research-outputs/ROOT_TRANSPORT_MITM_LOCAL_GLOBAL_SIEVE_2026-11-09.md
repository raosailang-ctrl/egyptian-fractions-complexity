# 平方根类传输：中心 K3 埃及分数族局部—全局筛选的增量结构

**日期：** 2026-11-09  
**承接：** 自适应 MITM 局部—全局筛选。  
**性质：** 一般模平方根传输引理 + 13 个参数的精确有限验证；不声称多项式时间或唯一性。

## 1. 核心观察

固定奇数参数 (t)，令 (M=h^2)，其中 (h=t(12t+1))。设 (p^a\parallel h)。所有通过局部 Jacobi 筛的 (q\mid D) 都满足
[
\left(\frac q p\right)=1\qquad(p\mid h).
]
因此 (q) 在每个模 (p) 下都是二次剩余。由 Hensel 引理，(q) 在模 (p^{2a}) 下有平方根。由中国剩余定理，(q) 是模 (M) 的平方。

这意味着：对所有通过局部筛的 (q)，同余
[
x^2\equiv -D/q\pmod M
]
具有同一个平方类。特别地，(q=1) 总是通过筛选，可作为共同锚点。

## 2. 平方根类传输引理

**引理（共同局部平方类上的根集传输）。** 设 (M=h^2) 为奇数，(gcd(D,M)=1)。若 (q,q'\) 是两个满足
[
(q/p)=(q'/p)=1\qquad\text{对每个 }p\mid h
]
的单位，则 (q'/q) 是模 (M) 的平方。若 (w^2\equiv q'/q\pmod M)，则映射
[
z\longmapsto wz\pmod M
]
给出以下两个根集之间的双射：
[
\{z:z^2\equiv-D/q\pmod M\}
\longrightarrow
\{z':z'^2\equiv-D/q'\pmod M\}.
]

**证明。** 对每个 (p\mid h)，有
[
\left(\frac{q'/q}{p}\right)
=\left(\frac{q'}p\right)\left(\frac qp\right)^{-1}=1.
]
Hensel 引理把模 (p) 的平方根提升到模 (p^{2a})，CRT 得到 (w^2\equiv q'/q\pmod M)。若 (z^2\equiv-D/q)，则
[
(wz)^2\equiv\frac{q'}q\cdot\frac{-D}q
]
这里需要注意目标方向：取 (w^2\equiv q/q'\pmod M)，则
[
(wz)^2\equiv\frac q{q'}\cdot\frac{-D}q
=-D/q'\pmod M.
]
乘以单位 (w) 可逆，故该映射为双射。证毕。

因此，以 (q_0=1) 为锚点，只需计算一次
[
\mathcal Z_0=\{z:z^2\equiv-D\pmod M\}.
]
对任意通过筛选的 (q)，取一个 (w_q) 满足
[
w_q^2\equiv q^{-1}\pmod M,
]
则完整根集为
[
\boxed{\mathcal Z_q=w_q\mathcal Z_0.}
]
这将“每个 (q) 都重新构造全部 CRT 根”改为“共同根集只构造一次，每个 (q) 只构造一个平方根乘子并作根集传输”。

## 3. 对 MITM 的作用

原 MITM 对每个 (q)：
1. 对每个 (p^a\parallel h) 求出 (-D/q) 的两个模 (p^{2a}) 根；
2. 通过 CRT 组合全部 (2^{\omega(h)}) 个根；
3. 对左半子集积 (X) 和每个根 (z)，查询右半余数 (zX^{-1}\pmod M)。

改进后：
1. 仅对锚点 (q_0=1) 构造完整根集 (mathcal Z_0)；
2. 对每个通过 Jacobi 筛的 (q)，求一个 (w_q^2\equiv q^{-1}\pmod M)；
3. 用 (mathcal Z_q=w_qmathcal Z_0) 得到该 (q) 的根集；
4. 继续执行原有 MITM 匹配。

它消除了每个 (q) 的 (2^{\omega(h)}) 组根的重复 CRT 组合，但每个 (q) 仍需计算一个模 (M) 平方根乘子，并且仍需遍历根集来产生目标余数。因而这是一个严格的结构性复用，不应在未测量前宣称总体运行时间必然显著下降。

## 5. 下一步

1. 研究 (q\mapsto q\ell) 或 (q\mapsto q/\ell) 时，乘子 (w_q) 能否增量更新。若变化因子本身是模 (M) 平方，则只需乘上预先缓存的平方根。
2. 将所有通过 Jacobi 条件的指数向量视为 (mathbb F_2) 线性方程组的解，研究 Gray-code 遍历，使相邻 (q) 之间只改变一个预先选定的核向量。
3. 用子集乘积的模余数分布和素数幂块位数选择左右分组，优化 MITM。
4. 继续保留 (t=7,69) 的非标准表示作为回归测试。

**边界：** 该引理只是局部平方类一致性的代数结果。它没有证明唯一性，没有给出多项式时间算法，也没有推出 P/NP 结论。
